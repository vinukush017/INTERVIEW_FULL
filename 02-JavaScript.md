# JavaScript Interview Preparation

## Core language

- [ ] Scope, hoisting, temporal dead zone, and closures
- [ ] var, let, and const
- [ ] this, call, apply, and bind
- [ ] Prototypes, classes, and inheritance
- [ ] Shallow copy versus deep copy
- [ ] Map, Set, WeakMap, and WeakSet
- [ ] Array methods: map, filter, reduce, sort, find, some, and every

## Async JavaScript

- [ ] Call stack and event loop
- [ ] Microtasks versus macrotasks
- [ ] Promises and error handling
- [ ] async/await
- [ ] Promise.all, allSettled, race, and any

## Practice prompts

- Implement debounce and throttle.
- Write Promise.all from scratch.
- Explain the output of closure and event-loop snippets.
- Create a deep-clone function and state its limitations.
