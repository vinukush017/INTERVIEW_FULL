# System Design Interview Preparation

## Discussion order

1. Clarify functional and non-functional requirements.
2. Estimate traffic, storage, and bandwidth.
3. Define APIs and the data model.
4. Draw the high-level design.
5. Deep-dive into bottlenecks and trade-offs.

## Topics

- [ ] Load balancing, caching, CDNs, and queues
- [ ] SQL versus NoSQL and partitioning
- [ ] Replication, consistency, and availability
- [ ] Rate limiting, retries, and idempotency
- [ ] Observability, security, and disaster recovery

## Practice systems

- URL shortener
- Chat application
- Notification service
- File storage service
