# Mock Interviews

Create one Markdown file per mock using YYYY-MM-DD-company-round.md.

Start with one mock per week in week 3. During the final two weeks, complete two mocks per week. Use a timer, speak your reasoning aloud, and review the recording or notes immediately afterward.

## Suggested rotation

1. DSA coding
2. JavaScript and React
3. Node.js, APIs, and SQL
4. Project deep dive
5. System design
6. Behavioral and HR
